Excel file format

  • Create a spreadsheet with exactly 3 columns.
  • Use these headers in the first row: Product Name, SKU, Quantity.
  • Keep one SKU per row and use whole numbers for quantity.
  • Do not add extra columns, formulas, or blank rows in the middle.
  • Save the file as .xlsx, .xls, or .csv.
Product Name SKU Quantity
Classic T-Shirt TS-1001 25
Black Mug MUG-404 12

Alternate format

You can also use 2 columns: Product Name and Quantity. Put the SKU in parentheses after the product name. The file will be parsed into the standard format and shown for confirmation before upload.

Product Name Quantity
Revix (3808) 25
Black Mug(MUG-404) 12
